Study Group Finder – Real-Time Web Application

A full-stack web application that allows students to register, create study groups, and chat in real time.
Built using Flask, Flask-SocketIO, SQLite, HTML, CSS, and deployed on Render.

🔗 Live Demo:
https://study-group-finder-yvxy.onrender.com

🚀 Features

🔐 User Authentication (Register & Login)

👥 Create & Join Study Groups

💬 Real-Time Group Chat using WebSockets (Socket.IO)

🧭 Clean UI with Navigation Bar

🗂️ SQLite Database Integration

🌐 Deployed on Render (Production Ready)

Installation & Setup (Local)
git clone https://github.com/likitha1212/study-group-finder.git
cd study-group-finder
pip install -r requirements.txt
python init_db.py
python app.py


Open browser:
👉 http://127.0.0.1:5000
